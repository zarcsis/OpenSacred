# The menus

Interface (`opensacred-game`), 2026-10-19 (#172).

## The original

The original's main menu and its creation of a hero are screens of its own interface, laid out in code from the `gui_*` atlases (docs/02 §11), and hold more than a new game.
While a game loads, it shows a loading screen of `PAK/*.bmp` (`ui/screens/loading0.png`, `loading1.png`, docs/02 §11).

## Ours

A main menu of New Game and Quit under the game's logo (`gui_main_logo`), in the original's interface font, on black.
New Game shows the seven classes of `--class` with their portraits (`gui_qbp_*`) and names; choosing one starts a game at the class's start, with no name and no difficulty, and the command line's other options.
The mouse chooses by pointing and clicking, the keyboard with the arrows, Enter and Esc.
While a game loads, the original's first loading screen shows, as high as the window.

## Why

The layout of the original's screens is not recovered; the interface is redesigned in M5 with the original's textures as skins.
Until then the menu starts a game of any class without the command line, and the play itself does not change.
